# A short history of GitHub

## Founding (2008)

GitHub was launched on **April 10, 2008**, founded by **Tom Preston-Werner,
Chris Wanstrath, PJ Hyett, and Scott Chacon**. It was built to make hosting
and sharing Git repositories easy, at a time when Git (created in 2005) was
powerful but hard to collaborate around.

## Growth

GitHub grew quickly to become the default home for open-source software.
Milestones along the way:

- **2012** — first major outside investment (Andreessen Horowitz).
- **2018** — passed 100 million repositories.
- **2019** — GitHub Actions (CI/CD) became generally available.
- **2020** — acquired **npm**, the JavaScript package registry.

## The Microsoft acquisition (2018)

On **June 4, 2018**, Microsoft announced it would acquire GitHub for
**$7.5 billion in Microsoft stock**. The deal closed in October 2018.
**Nat Friedman** became CEO after the acquisition; **Thomas Dohmke**
became CEO in **2021**.

Despite the acquisition, GitHub continues to operate as an independent
platform and still hosts competing technologies.

## The Octocat

GitHub's mascot is the **Octocat** — a cat with octopus tentacles,
designed by illustrator Simon Oxley (who also designed the original
Twitter bird). The Octocat is one of the most recognisable logos in
software.

## Today

GitHub is the largest source-code host in the world, with **over 100
million developers** and hundreds of millions of repositories. It also
launched **GitHub Copilot** (2021), an AI pair-programmer.
