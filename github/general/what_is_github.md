# What is GitHub?

GitHub is a web-based platform for hosting and collaborating on software
projects. At its core it stores **Git repositories** in the cloud and adds
a layer of collaboration tools on top: pull requests, issues, code review,
automation (GitHub Actions), and project management.

## In one sentence

GitHub is where developers store their code, review each other's changes,
track work, and automate building and shipping software — all around the
Git version-control system.

## What you can do on GitHub

- **Host code** in public or private repositories.
- **Propose changes** with pull requests and review them before merging.
- **Track work** with issues, labels, milestones, and Projects.
- **Automate** testing and deployment with GitHub Actions.
- **Publish** documentation with GitHub Pages and releases with assets.
- **Discover** open-source projects — GitHub hosts the largest collection
  of open-source software in the world.

## Who uses it

Individual developers, open-source communities, and companies of every
size. As of the mid-2020s GitHub has well over **100 million** registered
developers, making it the most widely used code-hosting platform.

## GitHub vs. the alternatives

The main comparable platforms are **GitLab** and **Bitbucket**. All three
host Git repositories; they differ in their built-in CI/CD, pricing, and
self-hosting options. GitHub is the largest by user count.
