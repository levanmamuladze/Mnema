# GitHub plans (overview)

GitHub offers tiers for individuals and organisations. Exact prices change
over time; the structure below is the stable, well-known shape.

## Individual & team plans

- **Free** — unlimited public and private repositories, unlimited
  collaborators, 2,000 Actions minutes/month for private repos, community
  support.
- **Team** — adds required reviewers, protected branches, code owners, and
  more Actions minutes. Billed per user, per month.
- **Enterprise** — adds SAML single sign-on, advanced auditing, GitHub
  Connect, and the option of **GitHub Enterprise Cloud** or
  **Enterprise Server** (self-hosted).

## Add-ons

- **GitHub Copilot** — AI pair-programmer, billed per seat.
- **GitHub Advanced Security** — secret scanning, code scanning (CodeQL),
  and dependency review, available on Enterprise.

## Common questions

**Is GitHub free?** Yes — the Free plan is genuinely usable for individuals
and small teams, including private repos.

**What's the difference between Cloud and Server?** *Enterprise Cloud* is
hosted by GitHub; *Enterprise Server* runs on your own infrastructure for
organisations with strict data-residency or compliance needs.
